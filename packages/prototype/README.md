# prototype

APM package for Matt Pocock's `prototype` skill. Invoke it as `/prototype` after installation.

Source: [mattpocock/skills](https://github.com/mattpocock/skills/tree/3cca18b368ae95cdbdebbff572ccafa662551015/skills/engineering/prototype).

Imported from upstream version `1.2.3`, commit `3cca18b368ae95cdbdebbff572ccafa662551015`. Package version `0.1.0` tracks this packaging separately.

The complete upstream skill directory is preserved byte-for-byte under `.apm/skills/prototype/`, including any agent metadata, templates, and reference files. The APM manifest, this README, and the upstream MIT license are packaging additions.

## Install

The source ZIP is available at `../../dist/prototype-0.1.0.zip`. Extract it and pass the extracted directory to `apm install`. It contains the complete APM package, including its manifest and license.

From a consuming project, use the local package path:

```powershell
apm install C:/Coding/my-apm/packages/prototype
```

Once this package is committed and pushed to the repository:

```sh
apm install MichaelGurevich/my-apm/packages/prototype
```

## Dependencies

No additional skills are required.
