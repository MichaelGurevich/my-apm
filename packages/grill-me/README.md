# grill-me

APM package for Matt Pocock's original `grill-me` skill. Invoke it as `/grill-me` after installation.

Source: [mattpocock/skills](https://github.com/mattpocock/skills/tree/a6bdfd9/grill-me).

Imported from upstream commit `a6bdfd9`, the last version of the standalone `grill-me` skill before upstream replaced it with `grilling` and `grill-with-docs`. Package version `0.1.0` tracks this packaging separately.

The upstream `SKILL.md` is preserved byte-for-byte under `.apm/skills/grill-me/`. The APM manifest, this README, and the upstream MIT license are packaging additions.

## Install

From a consuming project, use the local package path:

```powershell
apm install C:/Coding/my-apm/packages/grill-me
```

Once this package is committed and pushed to the repository:

```sh
apm install MichaelGurevich/my-apm/packages/grill-me
```

## Dependencies

None.
