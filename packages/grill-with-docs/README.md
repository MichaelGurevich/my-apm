# grill-with-docs

APM package for Matt Pocock's `grill-with-docs` skill. Invoke it as `/grill-with-docs` after installation.

Source: [mattpocock/skills](https://github.com/mattpocock/skills/tree/3cca18b368ae95cdbdebbff572ccafa662551015/skills/engineering/grill-with-docs).

Imported from upstream version `1.2.3`, commit `3cca18b368ae95cdbdebbff572ccafa662551015`. Package version `0.1.0` tracks this packaging separately.

The complete upstream skill directory is preserved byte-for-byte under `.apm/skills/grill-with-docs/`, including any agent metadata, templates, and reference files. The APM manifest, this README, and the upstream MIT license are packaging additions.

## Install

From a consuming project, use the local package path:

```powershell
apm install C:/Coding/my-apm/packages/grill-with-docs
```

Once this package is committed and pushed to the repository:

```sh
apm install MichaelGurevich/my-apm/packages/grill-with-docs
```

## Dependencies

APM installs these supporting upstream skills, pinned to the same commit:

- `grilling`
- `domain-modeling`
