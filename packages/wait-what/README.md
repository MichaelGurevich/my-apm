# wait-what

APM package for Matt Pocock's `wait-what` skill. Invoke it as `/wait-what` after installation.

Source: [mattpocock/skills](https://github.com/mattpocock/skills/tree/3cca18b368ae95cdbdebbff572ccafa662551015/skills/productivity/wait-what).

Imported from upstream version `1.2.3`, commit `3cca18b368ae95cdbdebbff572ccafa662551015`. Package version `0.1.0` tracks this packaging separately.

The complete upstream skill directory is preserved byte-for-byte under `.apm/skills/wait-what/`, including any agent metadata, templates, and reference files. The APM manifest, this README, and the upstream MIT license are packaging additions.

## Install

From a consuming project, use the local package path:

```powershell
apm install C:/Coding/my-apm/packages/wait-what
```

Once this package is committed and pushed to the repository:

```sh
apm install MichaelGurevich/my-apm/packages/wait-what
```

## Dependencies

No additional skills are required.
