This is the group index for the `engineering` skill pack. It contains two skills, discovered independently by harnesses that walk the skills root recursively:

- **grill-me** — interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree.
- **to-spec** — turn the current conversation into a spec and publish it to the project issue tracker, without an interview.

Pick `grill-me` when the plan is still uncertain and needs stress-testing. Pick `to-spec` when the shape of the work is already agreed and only needs writing down.
